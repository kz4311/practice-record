# 練習記録アプリ

iPad・iPhoneのブラウザで使える、日々の練習記録アプリです。

## できること

- 月間カレンダーで練習状況を確認
- 日ごとの練習項目をチェック
- 確認者のサインを記録
- 未実施の理由を記録
- 月間達成率を表示
- 練習メニューを変更

## ファイル構成

```text
practice-record-ipad/
├── index.html
└── README.md
```

## 保存方式

記録は、利用している端末のブラウザ内に自動保存されます。

- iPadで入力した記録は、そのiPadで確認できます。
- iPhoneやMacから同じ記録を自動的に見ることはできません。
- ブラウザのデータを消去すると、保存した記録も消える場合があります。

## 公開方法

GitHubリポジトリに `index.html` と `README.md` を保存し、Cloudflare PagesまたはCloudflareの公開機能と接続します。

このアプリは単一HTMLファイルで動作するため、通常はビルドコマンドを必要としません。

## 注意

学校管理のiPadで利用する場合は、学校側の設定によって外部URL、JavaScript、ブラウザ保存機能が制限されていないことを確認してください。
